# Paryavaran Mitra ERP

Office system for Paryavaran Mitra, an environmental and MPCB consultancy in Maharashtra.

This repository is the Phase 0 foundation: authentication, permissions, audit logging, English and Marathi, and the application shell. Business modules are specified and not built.

Read [docs/PROJECT_OVERVIEW.md](docs/PROJECT_OVERVIEW.md) first. Setup, MySQL, Redis, and backups are in [docs/DEPLOYMENT_GUIDE.md](docs/DEPLOYMENT_GUIDE.md).

```bash
composer install
php artisan test --compact
```
